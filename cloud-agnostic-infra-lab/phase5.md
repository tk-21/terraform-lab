```bash
# cloud-agnostic-infra-lab

## 概要
同一ワークロード（HTTP API + LB + AutoScaling）を AWS / GCP / Azure の3クラウドで
Terraform により構築し、設計・コスト・運用の差異を体験的に学ぶプロジェクト。

## モチベーション
「AWS一択」という思考の偏りを意図的に破り、
「比較検討した上でクラウドを選択できるエンジニア」になるため。

## 構成
- `aws/` : AWS構成（ALB + ASG + t4g.nano Spot）
- `gcp/` : GCP構成（Cloud LB + MIG + e2-micro Preemptible）
- `azure/` : Azure構成（LB + VMSS + B1s Spot）
- `comparison/` : 3クラウドの概念・コスト・運用比較
- `adr/` : Architecture Decision Records

## 学んだこと
→ [comparison/](./comparison/) および [adr/](./adr/) を参照

## コスト設計
- NAT Gateway禁止（月$32削減）
- Spot/Preemptible/Spot VM活用
- arm64（Graviton2 / arm64）優先
EOF

git init
git add .
git commit -m "feat: cloud-agnostic-infra-lab initial implementation"
```
