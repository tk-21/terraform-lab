# 社用PCセットアップ手順

対象: 新規配布PC、交換PC  
想定時間: 45-90分

## セットアップ前に確認

- ACアダプタ接続
- 安定したネットワーク接続（自宅Wi-Fi可）
- 社員アカウント情報を手元に準備
- 旧端末がある場合はデータ移行対象を整理

## 初期設定

1. OS初期ウィザードを完了
2. 社員アカウントでサインイン
3. ディスク暗号化状態を確認
4. 画面ロックを5分以内に設定

## 必須アプリ導入

1. VPNクライアント
2. Slack
3. ブラウザ（会社標準）
4. パスワードマネージャー
5. セキュリティエージェント（EDR）

## 開発者向け追加セットアップ

1. Git設定（`user.name`, `user.email`）
2. Docker / kubectl / Terraform / AWS CLI 導入
3. SSH鍵作成と公開鍵登録
4. リポジトリのクローン

## 動作確認チェック

- Slackの送受信ができる
- VPN接続できる
- 社内ポータルにアクセスできる
- `aws sts get-caller-identity` が成功する（AWS利用者のみ）

## トラブルシュート

- セキュリティエージェントが入らない
  - 再起動後に再実行
  - 管理者権限不足時はITサポートへ連絡
- アプリ配布ポータルにアクセスできない
  - VPN接続後に再試行
- 端末が重い
  - OSアップデート完了待ち後に再確認

## エスカレーション

- ITサポート: `it-support@company.internal`
- 至急対応: Slack `#help-it`
