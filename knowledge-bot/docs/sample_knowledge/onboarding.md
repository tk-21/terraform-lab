# 新入社員オンボーディングガイド

このドキュメントは、入社初日から1週間で必要になるITセットアップをまとめた手順書です。

## 到達目標

- 社内アカウントにログインできる
- Slack/メール/VPNを利用できる
- 開発用リポジトリへアクセスできる
- 緊急時の問い合わせ先を把握している

## 事前に手元に用意するもの

- 社員番号
- 私用スマートフォン（MFA登録用）
- ITから受領した初期パスワード
- 配布済みの社用PC

## Day 1 チェックリスト

1. 社員アカウントの初回ログイン
2. 初期パスワード変更
3. MFA（多要素認証）登録
4. 社用PCセットアップ（`laptop_setup.md`）
5. VPN設定（`vpn_setup.md`）
6. Slackログインと主要チャンネル参加

## Day 2-3 チェックリスト

1. AWSアクセス申請（`aws_account_access.md`）
2. 開発リポジトリへのアクセス確認
3. 必要ツール（Docker, kubectl, Terraform）の導入
4. 自チームの定例会参加

## Day 4-5 チェックリスト

1. パスワードリセット手順の確認（`password_reset.md`）
2. インシデント連絡導線の確認（`incident_contact.md`）
3. セキュリティ研修の受講完了
4. メンターと環境チェック最終確認

## よくあるつまずき

- 初期パスワードの有効期限切れ
  - ITサポートに再発行依頼
- MFAアプリの機種変更でログイン不可
  - サポート窓口でMFAリセット依頼
- VPN接続不可で社内サイトに入れない
  - 先に `vpn_setup.md` の切り分け手順を実施

## 問い合わせ先

- ITサポート窓口: `it-support@company.internal`
- Slack: `#help-it`
- 緊急時: `incident_contact.md` を参照
