# インシデント発生時の連絡先

このドキュメントは、障害発生時に「誰に」「どの順番で」連絡するかを定義します。

## 連絡優先順位

1. Slack `#incident` に第一報を投稿
2. オンコールエンジニアへメンション/電話
3. ITマネージャーへエスカレーション
4. 必要に応じて事業責任者へ共有

## 第一報テンプレート

以下テンプレートを `#incident` に投稿してください。

```text
[SEV?] 事象概要:
発生時刻:
影響範囲:
暫定対応:
次回更新予定:
担当者:
```

## 重大度（SEV）目安

- `SEV1`: 全社影響、業務停止、顧客影響大
- `SEV2`: 一部機能停止、回避策あり
- `SEV3`: 軽微障害、影響限定

## 初動の5分で実施すること

1. 事実ベースで現象を確認（憶測を混ぜない）
2. 影響範囲を一次評価
3. ロールバック可否を判定
4. 暫定復旧を優先
5. 10-15分間隔で状況更新

## 連絡先

- Slack: `#incident`
- オンコール: 会社オンコール表を参照
- ITマネージャー: `it-manager@company.internal`

## 収束後

1. インシデントチケットをクローズ
2. 24時間以内にポストモーテム作成
3. 再発防止アクションのオーナーと期限を設定
