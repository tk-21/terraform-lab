# VPN接続方法

社内システム（社内ポータル、内部Git、管理画面）へアクセスするにはVPN接続が必要です。

## 事前条件

- 社員アカウントが有効である
- MFA登録が完了している
- VPNクライアントがインストール済み

## 接続手順

1. VPNクライアントを起動
2. サーバアドレス `vpn.company.internal` を指定
3. 社員番号とパスワードを入力
4. MFAコードを入力
5. 接続ステータスが `Connected` になったことを確認

## 接続確認

- `https://portal.company.internal` にアクセスできる
- 社内DNS名（`*.internal`）が名前解決できる
- 業務システムへログインできる

## 切断手順

1. 作業完了後にVPNクライアントを開く
2. `Disconnect` を実行
3. 未保存作業がないことを確認

## よくあるエラーと対処

- `Authentication failed`
  - パスワード期限切れの可能性あり
  - `password_reset.md` の手順で再設定
- `Gateway unreachable`
  - 自宅ネットワーク断またはDNS不調の可能性
  - ルータ再接続、別回線テザリングで再試行
- 接続できるが社内サイトが遅い
  - 大容量同期ツールを停止
  - 混雑時間帯は再接続で改善する場合あり

## セキュリティ注意

- 公共Wi-Fi利用時は必ずVPN接続後に業務アクセス
- VPN接続中の私用サービス利用は最小限にする
- 不審な切断/再接続が続く場合は即時報告
