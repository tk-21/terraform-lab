# AWSアカウントアクセス申請

AWS環境（開発/検証/本番）へアクセスするには、利用目的に応じたロール申請が必要です。

## 申請前の確認

- 配属チームが確定している
- 受講必須のセキュリティ研修を完了している
- 上長の承認方針を確認済み

## 申請手順

1. 社内ポータルへアクセス
2. 「AWSアクセス申請」を選択
3. 対象アカウント（dev/stg/prod）を指定
4. 必要ロール（ReadOnly/PowerUser/Admin）を選択
5. 利用目的と期間を記入
6. 上長承認フローへ提出

## 承認後の初回ログイン

1. SSOポータルへログイン
2. 対象AWSアカウントを選択
3. CLI利用者は `aws configure sso` を実施
4. `aws sts get-caller-identity` で接続確認

## ロール選択の目安

- `ReadOnly`: 調査、ログ確認、監査
- `PowerUser`: 検証環境の構築・更新
- `Administrator`: 限定された運用担当のみ

## 注意事項

- 本番環境は最小権限・期限付き付与が原則
- 共有アカウント禁止（個人単位で付与）
- 不要になった権限は速やかに剥奪申請

## 承認が遅い場合

- 申請番号を添えて `it-support@company.internal` へ問い合わせ
- 緊急度が高い場合は上長からIT管理者へエスカレーション
