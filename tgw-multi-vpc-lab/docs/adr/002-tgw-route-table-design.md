# ADR-002: TGWルートテーブルを2テーブル構成にする

## ステータス
採用済み

## コンテキスト
Spoke間通信を禁止しながら、HubとSpoke間の通信は許可するポリシーを実装する必要がある。

## 決定
Spoke用とHub用の2つのルートテーブルを作成し、SpokeのルートテーブルにはHub CIDRのみを伝播させる。
