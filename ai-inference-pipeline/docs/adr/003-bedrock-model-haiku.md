# ADR-003: BedrockモデルにClaude 3 Haikuを採用

## ステータス
Accepted

## コンテキスト
データ分析・要約タスクにBedrockを使用する際、複数のモデルから選択する必要があった:
- Claude 3 Opus
- Claude 3 Sonnet
- Claude 3 Haiku

## 決定
Claude 3 Haikuを採用し、モデルIDをIAMポリシーでHaikuのみに制限する。
